# Performance pass

- One blocking local stylesheet: core.css
- Product, photo and site code load only when near the viewport
- Below-fold video files are not prewarmed on page load
- Cartoon cover is a single cached SVG wrapper around the approved JPEG
- Versioned static assets cache for one year
- HTML/CSS/JS/SVG support Brotli/Gzip
- Desktop and mobile section spacing normalized with safe-area padding
